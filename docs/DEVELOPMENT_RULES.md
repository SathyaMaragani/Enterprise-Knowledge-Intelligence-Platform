# Development Rules

1. Do not mix subject implementations.
2. Every major feature must identify its subject.
3. Every algorithm must have tests.
4. Every algorithm should document time and space complexity.
5. No premature integration.
6. No unnecessary dependencies.
7. No hardcoded secrets.
8. Use environment variables for configuration.
9. Write documentation alongside major features.
10. Every milestone must be tested before moving to the next.
11. Do not rewrite working code unnecessarily.
12. Preserve backwards compatibility where practical.
