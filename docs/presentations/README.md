# Review presentations and reports

Every review deck of the project, with a PDF copy that opens in the browser, and the final review reports. Folders run in review order inside each subject.

The decks are kept as they were presented, so earlier ones describe plans that later changed. For example, DBE-DSD Review 2 lists Node.js/FastAPI and Pinecone as candidates, and OSSP Review 2 covers Weeks 1–6 only. [`docs/PROJECT_OVERVIEW.md`](../PROJECT_OVERVIEW.md) and the subject documents describe what was actually built.
