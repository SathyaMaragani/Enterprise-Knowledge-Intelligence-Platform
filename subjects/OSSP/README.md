# OSSP (Operating Systems & System Programming) Subject Responsibilities

This subject is responsible for the **ShellForge Linux administration shell**.

## Core Modules:
- **CO1**: Custom REPL shell, Linux system calls, command execution.
- **CO2**: Process creation (fork, exec, wait), process lifecycle, job control.
- **CO3**: Pipes, named pipes/FIFOs, signals, process groups, sessions.
- **CO4**: Virtual memory concepts, malloc/free, mmap, page faults, memory debugging.
- **CO5**: File descriptors, open/read/write/close, directories, buffered/unbuffered I/O, memory mapped files.
- **CO6**: POSIX threads, mutexes, condition variables, semaphores, race conditions, deadlock demonstrations.
